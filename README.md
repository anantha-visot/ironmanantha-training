# Pulse Caller

Android app that reads live heart rate from a WHOOP strap (Heart Rate Broadcast on) or any
Bluetooth heart-rate strap, and speaks it through your earphones — with the app closed and the screen off.

- Calls BPM and 5-minute average every N minutes (default 5)
- Zone alerts when you stay above/below your zone, plus "back in zone"
- Runs as a foreground service with an ongoing notification (Stop button there)

Every push to the `pulse-caller-app` branch builds an APK and publishes it under **Releases**.
